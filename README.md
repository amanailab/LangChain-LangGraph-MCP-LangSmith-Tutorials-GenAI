# 🚀 LangChain, LangGraph, MCP & LangSmith Tutorials — Generative AI

Welcome to the **AmanAI Lab** repository! This project contains hands-on Python examples and tutorials covering LangChain, Large Language Models (LLMs), LangGraph, Model Context Protocol (MCP), and LangSmith.

The goal is to help developers and aspiring AI engineers understand Generative AI concepts through simple explanations and practical code examples.

## 🎯 What You'll Learn

- **LangChain:** Models, prompts, messages, chains, output parsers, streaming, batching, and chat history.
- **LangGraph:** Build stateful AI workflows, agents, and multi-agent systems.
- **MCP (Model Context Protocol):** Connect AI applications with external tools and services.
- **LangSmith:** Trace, debug, evaluate, and monitor LLM applications.
- **Generative AI:** Understand LLM integration and build practical AI applications using Python.

## 🛠️ Tech Stack

- Python
- LangChain
- Groq API
- Large Language Models (LLMs)
- LangGraph, MCP, and LangSmith as covered in the relevant tutorials

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/amanailab/LangChain-LangGraph-MCP-LangSmith-Tutorials-GenAI.git
cd LangChain-LangGraph-MCP-LangSmith-Tutorials-GenAI
```

### 2. Create a Virtual Environment

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

If the repository includes a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

Otherwise, install the dependencies required by the specific example you want to run.

### 4. Configure Environment Variables

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Get your API key from the [Groq Console](https://console.groq.com/).

**Security:** Never commit your `.env` file or expose API keys in source code. The `.env` file should remain local and be excluded through `.gitignore`.

### 5. Run an Example

For example:

```bash
python direct_groq.py
```

Or run a LangChain example:

```bash
python with_langchain.py
```
